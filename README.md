# Pulse

Pulse is a customizable interval timer for workouts and other time-based routines.

## Features

- Custom timers with multiple intervals
- Work and rest intervals
- Interval repetitions
- Pause, resume, restart, next and previous interval controls
- Sound feedback for timer events
- Haptic feedback
- Background timer execution on Android
- Foreground service notification
- Keep-awake mode during active workouts
- Lock screen mode to prevent accidental interaction
- Responsive portrait and landscape layouts

## Tech Stack

- HTML
- CSS
- JavaScript
- Capacitor
- Android
- Python
- DRF
- Capacitor Haptics
- Capacitor Keep Awake
- Android Foreground Service
